# Changelog

## 0.2.0 - 2026-09-10

### Release
- Rebranded product to **HypeTek CPU Throttling**.
- Added native EXE launcher with UAC elevation and foreground startup.
- Added live CPU utilization and dynamic clock estimate plus visible active frequency limit.
- Added matching-profile detection, profile import/export and diagnostic export.
- Added HypeTek cyberpunk appearance system with configurable wallpaper and dimming.
- Added optional editor-warning visibility in Settings.
- Removed misleading ACPI temperature display; CPU package temperature requires a reliable external sensor source.
- Preserved v0.1.x profile/settings paths for compatibility.
- No manual unhide of the Windows MHz option is required.

## 0.1.7-ui-fix - 2026-09-07
- Improved profile-editor layout and DC option visibility.

## 0.1.6-storage-cleanup - 2026-09-07
- Cleaned runtime storage paths and retained product-specific profile/log locations.

## 0.1.5-power-schemes - 2026-09-07
- Added installed Windows power-scheme selection and activation.

## 0.1.4-single-window - 2026-09-07
- Added hidden PowerShell launch path so the normal GUI does not keep a console window open.

## 0.1.3-live-log - 2026-09-07
- Added live execution logging and equivalent `powercfg` command display.

## 0.1.2-ps51-fix - 2026-09-07

## 0.1.1-hotfix - 2026-09-07

## 0.1.0 - 2026-09-07
